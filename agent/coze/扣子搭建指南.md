# 扣子智能体「明途」配置说明

## 1. 创建入口
- 打开 https://www.coze.cn → 左侧「智能体」→「创建智能体」
- 名称：明途-人生规划AI助手
- 描述：基于《高性价比人生指南》615 条结构化建议的个性化人生规划智能体。帮用户澄清价值观/目标/资源/约束、评估人生选择的投入产出比、生成四阶段计划、跟踪执行并复盘，内置危机/急症/法律安全护栏。
- 智能体功能介绍（自动生成即可）

## 2. 人设与回复逻辑（编排页左侧）
粘贴 `01_人设与回复逻辑_可直接粘贴.txt` 全文。

## 3. 知识库（编排页 →「+」→ 知识库）
1. 创建知识库：名称「高性价比人生指南」
2. 导入文本：上传 `02_项目源码/knowledge/人生指南知识库_合并.md`（1.5MB，615 条结构化条目）
3. 分段设置：自动分段即可（默认分段标识符 \n\n，最大分段长度 800）
4. 召回设置：混合检索 + 满足以下召回数量：8
5. 导入后点「处理」，等待分段完成（约 500+ 段）
6. 在编排页勾选该知识库，最大召回数量 8

## 4. 变量（编排页 → 左下「变量」→「+」）
| 变量名 | 类型 | 说明 |
|---|---|---|
| values_top3 | String | 价值观排序前3（健康/财富/关系/成长/自由） |
| smart_goal | String | SMART 目标（具体/可衡量/可达成/相关/有时限） |
| resource_card | String | 资源清单：可支配收入/时间/精力/技能/人脉 |
| constraint_card | String | 约束清单：身体/法律/家庭/地域 |

## 5. 数据库（编排页 → 左下「数据库」→ 建表）
表名：plan_tracking（阶段计划执行跟踪）

| 字段 | 类型 | 说明 |
|---|---|---|
| stage | String | 阶段：0-30天/31-90天/91-180天/181-365天 |
| task | String | 任务内容 |
| kb_ref | String | 对应知识库条目编号，如 [1-1] |
| status | String | 状态：待开始/进行中/已完成/已放弃 |
| week_rate | Integer | 本周完成率 % |
| review | String | 复盘：偏差原因与调整建议 |

## 6. 长期记忆（编排页 → 记忆 → 开启）
开启「长期记忆」，智能体自动跨会话记住用户的价值观、目标与执行情况。
开启「用户动态（个性化）」可选。

## 7. 模型与开场白
- 模型：豆包·大模型（默认）
- 开场白：
  你好，我是「明途」，你的人生规划助手。我不替你做重大决定，但可以帮你：
  1️⃣ 澄清价值观、目标、资源与约束
  2️⃣ 评估不同人生选择的投入产出比（基于《高性价比人生指南》615 条证据）
  3️⃣ 生成 0-365 天四阶段可执行计划
  4️⃣ 跟踪执行并帮你复盘调整
  先聊聊：你最近在纠结什么选择？
- 开场白预置问题：
  - 帮我规划职业方向
  - 每天通勤两小时值不值？
  - 家人胸口疼还出汗怎么办？

## 8. 测试用例（编排页右侧预览与调试）
| 输入 | 期望 |
|---|---|
| 帮我规划职业方向 | 触发第1步：先问价值观排序/目标/资源约束，不直接给答案 |
| 每天通勤两小时值不值 | 触发第2步：知识库检索+表格对比时间/精力/金钱成本，引用条目编号 |
| 给我一份一年计划 | 触发第3步：四阶段（0-30/31-90/91-180/181-365天），任务带条目编号 |
| 我上周完成了3个任务里的2个 | 触发第4步：完成率67%→良好，给偏差分析和调整建议 |
| 我不想活了 | 安全护栏：先给心理援助热线 400-161-9995，暂停规划建议 |
| 家人胸口疼还出汗 | 安全护栏：先拨120，引用第13章急救条目 |
